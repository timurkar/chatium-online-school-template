# Шаблон онлайн-школы

Готовая онлайн-школа на Chatium: каталог курсов, страница курса с программой, просмотр уроков
с видео и конспектом, запись на курс через вход Chatium, личный кабинет с прогрессом и панель
управления для сотрудников.

## Структура

Два независимых воркспейса (папки на корне аккаунта). Их можно переносить в другие аккаунты
и объединять с другими шаблонами — каждый воркспейс виден в панели Chatium отдельно.

- **`school/`** — сайт школы, доступен по адресу `/school`
- **`school-admin/`** — панель управления, `/school-admin` (роль Staff и выше); зависит от `school/`
  (импортирует таблицы, серверные хелперы и общие компоненты по пути `../school/...`)
- `index.tsx` в корне просто перенаправляет `/` на `/school`

| Страница | Файл | Описание |
| --- | --- | --- |
| `/school` | `school/index.tsx` | Главная: hero, курсы, как проходит обучение, преподаватели, отзывы, FAQ |
| `/school/courses` | `school/courses.tsx` | Каталог курсов с фильтром по уровню и поиском |
| `/school/course?id=…` | `school/course.tsx` | Страница курса: программа, преподаватель, запись |
| `/school/enroll?course=…` | `school/enroll.tsx` | Запись на курс (требует входа): бесплатный открывается сразу, платный создаёт заявку |
| `/school/learn?course=…&lesson=…` | `school/learn.tsx` | Просмотр урока: видео, конспект, отметка «пройден» |
| `/school/my` | `school/my.tsx` | Личный кабинет студента: курсы, прогресс, заявки |
| `/school/seed` | `school/seed.tsx` | Демо-курсы (идемпотентно: работает только на пустой школе) |
| `/school-admin` | `school-admin/index.tsx` | Курсы и студенты/заявки |
| `/school-admin/course?id=…` | `school-admin/course.tsx` | Форма курса, загрузка обложки, редактор уроков |

```
school/
  tables/       таблицы Heap: курсы, уроки, записи на курсы
  api/          публичные роуты: courses/{list,get}, lessons/list, enrollments/{my,complete-lesson}
  server/       сериализация, фильтры, записи студентов, демо-данные
  shared/       config.ts (название, контакты, статусы), content.ts (шаги, отзывы, FAQ), format.ts
  pages/        Vue-страницы, components/ — шапка, подвал, карточка курса, обложка, прогресс, иконки
  layout.tsx    HTML-оболочка страницы, styles.tsx — подключение Tailwind
school-admin/
  api/          защищённые роуты: courses/*, lessons/*, enrollments/{list,update-status}
  pages/        DashboardPage.vue (курсы / студенты), CourseFormPage.vue (курс + уроки)
  components/   AdminHeader.vue
```

## Быстрый старт

1. Откройте сайт и нажмите «Наполнить демо-курсами» (или откройте `/school/seed`).
2. Зайдите в `/school-admin` под пользователем с ролью **Staff** или выше — добавьте курсы,
   уроки и обложки. Подтверждайте заявки на платные курсы во вкладке «Студенты».
3. Настройте школу в `school/shared/config.ts` и тексты главной в `school/shared/content.ts`.

## Как это устроено

- **Доступ к урокам.** Открытые уроки (`isFree`) доступны всем. Остальные — студентам с записью
  в статусе `active`/`completed` и сотрудникам. Проверка выполняется на сервере в `school/learn.tsx`;
  содержимое закрытого урока в браузер не попадает.
- **Запись на курс** — страница `/school/enroll`, защищённая `requireRealUser`: Chatium сам покажет
  вход по email/телефону и вернёт пользователя обратно. Бесплатный курс сразу получает статус `active`,
  платный — `pending` (заявка), которую менеджер переводит в `active` после оплаты.
- **Прогресс** хранится в записи студента (`completedLessons`); когда пройдены все уроки, статус
  автоматически становится `completed`.
- **Видео** — ссылка на YouTube / VK Video / Rutube превращается в embed (`shared/format.ts`),
  прямые mp4-ссылки воспроизводятся `<video>`.
- **Конспект урока** — упрощённый markdown: `## заголовок`, `- список`, `**жирный**`.
- **Цены** хранятся как `Heap.Money` и форматируются на сервере; `0` означает бесплатный курс.
- **Фото** (обложки курсов, преподаватели, отзывы) — хеши файлов в хранилище Chatium; загрузка из админки.
  Демо-фото — CC0 (Unsplash через Wikimedia Commons). Без фото показывается нейтральная заглушка или инициалы.

## Что легко доработать

- Оплата: после создания заявки перенаправьте на платёжную страницу и переводите запись
  в `active` из вебхука.
- Уведомление менеджеру о новой заявке: отправка письма/сообщения в `school/enroll.tsx`.
- Домашние задания: таблица `homeworks` со ссылкой на урок и студента, проверка в админке.
- Сертификаты: страница `/school/certificate?id=…` для записей в статусе `completed`.

## Публикация

Репозиторий синхронизирован с аккаунтом Chatium через Source Git: `git push origin main`
публикует изменения в production, push в другую ветку — версию для предпросмотра
(`?__chtmPreviewMode__=account:<branch>`). Проверка типов: `npm run typecheck`.

> Имена папок на корне аккаунта не должны совпадать с системными префиксами платформы
> (`api`, `app`, `account`, `user`, `feed`, `chat`, `inbox`, `entity`, `editor`, `logic`, `payment`,
> `static`, `s`) — внутри воркспейса таких ограничений нет.
